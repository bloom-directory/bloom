Know what the limits cover

Automatic sessions initially cover eligible Polymarket buys using nominal pUSD collateral. These are not limits on the total USD value of your wallet. Hyperliquid, other apps and uncovered assets require an exact action review. Native assets require explicit unit limits in a separate reviewed proposal.

Polymarket rollout gate: automatic BUY coverage needs the updated order-accounting package. The currently released package still requests individual approvals.
